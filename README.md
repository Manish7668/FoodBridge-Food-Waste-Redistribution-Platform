# FoodBridge – Food Waste Redistribution Platform

Production-oriented full-stack monorepo implementing the core loop: Donate → Match → Claim → Pickup → Deliver → Confirm → Measure Impact.

## Stack
React + Vite + TypeScript + Tailwind + React Router + TanStack Query + React Hook Form/Zod; Node + Express + TypeScript + Mongoose + JWT + Socket.IO; MongoDB; Docker.

## Quick start
1. `cp .env.example .env`
2. Start MongoDB: `docker compose up -d mongodb`
3. `npm install`
4. `npm run dev`

Frontend: http://localhost:5173 · API: http://localhost:4000 · API docs: http://localhost:4000/api/docs

## Seed
`npm --workspace backend run seed`
Demo accounts are printed by the seed command. Do not use them in production.

## Safety
FoodBridge facilitates redistribution; it does not certify food safety. Donors and receiving organizations remain responsible for applicable local food-safety requirements.
